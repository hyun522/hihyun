# Hyun Portfolio

> 개인 포트폴리오 웹사이트

🔗 Demo
https://hyunportfolio.vercel.app

<br />

## 프로젝트 목적

개발 경험과 프로젝트를 효과적으로 전달하기 위해 제작한 개인 포트폴리오 웹사이트입니다.

이력서만으로는 전달하기 어려운 프로젝트 경험과 문제 해결 과정을 함께 보여주고자 했습니다.

또한 프로젝트를 진행하며 Next.js App Router 구조를 다시 학습하고, GSAP, tsParticles, Kakao Map 등 다양한 라이브러리를 직접 적용해보며 기술 탐색과 구현 경험을 쌓았습니다.

<br />
